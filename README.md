# LotusVerse

A free desktop app for managing custom Magic: The Gathering card sets: import your sets, browse cards, build decks with synergy suggestions, and export to Tabletop Simulator and Cockatrice.

## Download

**[Download the latest version for Windows](https://github.com/LotusVerseStudios/LotusVerse/releases/latest)**

Get **LotusVerse.Setup.x.x.x.exe** from the Assets list and run it.

- **Windows only for now.** There is no Mac or Linux version yet. If you use a Mac and would like to help get one working, please get in touch.
- **Windows may show a "Windows protected your PC" warning.** The installer isn't code-signed yet. Click **More info**, then **Run anyway**.
- LotusVerse starts empty and includes no cards, sets, or art. You import your own sets from Magic Set Editor (see **Help → Getting Started** inside the app).

## Features

- Import custom sets and browse their cards
- Deck builder for Commander and Standard, with synergy suggestions, mana curve, and land base suggestions
- Export decks to Tabletop Simulator, Cockatrice (.cod), plain-text lists, and printable proxy PDFs
- Share whole sets as set packages with other LotusVerse users
